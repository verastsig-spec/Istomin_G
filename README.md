Movie Library

**Автор:** [Глеб Истомин]

Описание
Приложение для ведения личного списка фильмов. Позволяет добавлять фильмы, указывать их жанр, год и рейтинг. Данные автоматически сохраняются в JSON-файл.

Функционал
- Добавление фильмов с валидацией данных.
- Фильтрация списка по жанру и году в реальном времени.
- Постоянное хранение данных в `movies.json`.

Как запустить
1. Установите зависимости: `pip install PyQt6`
2. Запустите файл: `python main.py`

Тестирование
- Попробуйте ввести в поле "Рейтинг" значение 11 или текст — программа выдаст ошибку.
- Введите часть жанра (например, "Драма") в поле фильтра — таблица обновится мгновенно.
